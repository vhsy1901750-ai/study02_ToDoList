# study02_ToDoList

하루 10-20개 정도의 할 일을 관리하는 개인용 웹 앱을 만드는 저장소입니다. 브라우저에서 바로 열리고 새로고침해도 할 일이 남는 앱을, 외부 라이브러리 없이 순수 자바스크립트로 만드는 것이 목표입니다.

지금 이 저장소에는 앱을 만들기 위한 문서가 들어 있습니다. 앱 코드는 아직 올라오지 않았습니다.

## 어떤 앱인가요

- 할 일을 추가, 수정, 삭제하고 완료 여부를 체크합니다.
- 업무, 개인, 공부 카테고리로 나눠 봅니다.
- 지금 보고 있는 카테고리의 진행률을 막대와 숫자로 보여 줍니다.
- 할 일은 브라우저(localStorage)에 저장되어 새로고침해도 남아 있습니다.
- PC와 휴대폰 브라우저 모두에서 씁니다.

자세한 요구사항은 아래 PRD에 있습니다.

## 문서 안내

| 문서 | 무엇이 들어 있나요 | 이럴 때 보세요 |
| --- | --- | --- |
| [PRD](docs/PRD.md) | 기능, 화면 구성, 데이터 저장 방식, 오류 처리, 테스트, 완료 기준 | 무엇을 만들지 확인할 때 |
| [단계별 프롬프트](docs/claude-code-prompts.md) | PRD를 Claude Code에 붙여 넣어 쓸 수 있게 나눈 5단계 지시문 | Claude Code로 앱을 처음부터 만들 때 |
| [구현 프롬프트 폴더](docs/prompts/) | 위 5단계 지시문을 단계마다 파일 하나로 나눈 것 | 지금 진행할 단계의 프롬프트만 열어 복사할 때 |
| [구현 계획](docs/superpowers/plans/2026-10-02-todo-app.md) | 8개 작업으로 나눈 상세 계획. 작업마다 코드, 테스트, 실행 명령 포함 | 한 단계씩 직접 구현하거나 진행 상황을 확인할 때 |

모든 문서는 PRD를 기준으로 합니다. 내용이 서로 다르면 PRD를 따릅니다.

## 단계별 프롬프트 쓰는 법

[단계별 프롬프트](docs/claude-code-prompts.md)는 다음 다섯 단계로 나뉘어 있습니다.

1. 프로젝트 준비와 할 일 로직
2. 저장 형식과 데이터 검증
3. 화면 구성과 렌더링
4. 사용자 동작 연결
5. 전체 점검과 배포

각 단계의 프롬프트를 Claude Code에 붙여 넣고, 그 단계가 끝나면 문서에 적힌 완료 확인 항목을 직접 확인한 뒤 다음 단계로 넘어가 주세요. 한 번에 여러 단계를 붙여 넣지 않는 것이 좋습니다.
