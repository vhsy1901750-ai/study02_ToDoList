# study02_ToDoList

하루 10-20개 정도의 할 일을 관리하는 개인용 웹 앱입니다. 브라우저에서 바로 열리고, 새로고침하거나 브라우저를 다시 켜도 할 일이 그대로 남아 있습니다. 외부 라이브러리 없이 순수 자바스크립트로 만들었습니다.

## 웹에서 바로 써 보기

**https://vhsy1901750-ai.github.io/study02_ToDoList/**

PC와 휴대폰 브라우저 모두에서 쓸 수 있습니다.

## 이렇게 씁니다

**할 일 추가**: 입력칸에 제목을 쓰고 카테고리(업무, 개인, 공부)를 고른 뒤 Enter를 누르거나 [추가]를 누릅니다. 추가한 뒤에도 입력칸에 커서가 남아 있어 다음 할 일을 바로 이어서 쓸 수 있습니다.

**완료 표시**: 할 일 왼쪽의 체크박스를 누르면 제목에 줄이 그어지고 위쪽 진행률이 바로 바뀝니다. 한 번 더 누르면 되돌아갑니다.

**수정**: [수정]을 누르면 그 자리에서 제목과 카테고리를 고칠 수 있습니다. Enter나 [저장]으로 저장하고, Esc나 [취소]로 취소합니다.

**삭제**: [삭제]를 누르면 확인 창이 뜨고, 확인하면 지워집니다.

**카테고리별로 보기**: 위쪽 탭(전체, 업무, 개인, 공부)을 고르면 목록과 진행률이 그 카테고리 기준으로 바뀝니다. 마지막으로 고른 탭은 다음에 열 때도 그대로입니다.

**완료 항목 정리**: 맨 아래 [완료 항목 정리]를 누르면 지금 보고 있는 탭의 완료한 할 일을 한꺼번에 지웁니다. 지울 항목이 없으면 버튼이 흐리게 표시됩니다.

## 데이터는 이 브라우저에만 저장됩니다

할 일은 서버가 아니라 지금 쓰는 브라우저 안(localStorage)에 저장됩니다. 그래서 다음 점을 알아 두시면 좋습니다.

- PC와 휴대폰의 목록은 서로 이어지지 않습니다. 기기마다 따로 관리됩니다.
- 브라우저의 사이트 데이터를 지우면 할 일도 함께 사라집니다.
- 저장된 데이터가 어떤 이유로 망가지면 "저장된 데이터를 읽지 못해 빈 목록으로 시작합니다."가 뜹니다. 이때 원래 데이터는 버리지 않고 `todo-app-backup`이라는 이름으로 따로 보관해 둡니다.

## 내 컴퓨터에서 실행하기

`index.html`을 더블클릭해서 열면 동작하지 않습니다. 이 앱은 ES 모듈을 쓰기 때문에 반드시 웹 서버를 거쳐 열어야 합니다. 저장소 폴더에서 아래 명령을 실행한 뒤 브라우저로 `http://localhost:8000/`을 엽니다.

```bash
python -m http.server 8000
```

## 테스트

할 일 추가, 수정, 진행률 계산, 망가진 데이터 감지 같은 핵심 로직은 자동 테스트로 확인합니다. Node.js만 있으면 되고 따로 설치할 패키지는 없습니다.

```bash
npm test
```

화면 동작은 [PRD](docs/PRD.md) 8.2절의 체크리스트로 직접 확인합니다.
